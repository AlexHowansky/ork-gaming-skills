# PF2e / SF2e rules reference

All data lives under this skill's directory: `data/{pf2e,sf2e}/<category>.txt`, **one record per line**. Source release tags: `data/VERSION`.

## How to look things up (use Bash)

`scripts/pf.py` is at this skill's base directory. Always call it with that absolute path.
- `scripts/pf.py "Name" ["Name2" ...]` prints full records with one field per line. It matches exact names first, then prefixes, then substrings, case-insensitive. You can pass several names in one call.
- `scripts/pf.py -s 'regex'` runs a full-text search and lists matching record names with context. Use it for concepts or when you don't know the name.
- Options:
  - `-g pf2e|sf2e`: limit to one game.
  - `-f <category>`: limit to one file, e.g. `creatures`, `spells`, `rules`, `conditions`.
  - `-n N`: maximum number of results.
  - `-r`: raw single-line output.
- Don't use the Grep or Read tools on the data files. Records can be up to about 20 KB on a single line, and those tools truncate long lines. Plain `grep` through Bash is fine, e.g. `grep -i '^fireball|' data/pf2e/spells.txt`.

Strategy:
1. For a named thing (spell, feat, monster, item, condition, trait), run `pf.py "Name"`.
2. For general rules, run `pf.py -s 'topic' -f rules`, then `pf.py "Journal > Page"`. Examples:
   - `GM Screen > Encounter Budget`
   - `GM Screen > DCs by Level`
   - `GM Screen > Treat Wounds`
   - `Classes > Wizard`
   - `Archetypes > <name>`
3. For creature background (ecology, society, behavior, appearance), run `pf.py "Name" -f creature-lore`. Lore is left out of normal lookups to keep stat blocks small, so only fetch it when the question needs it.
4. For trait meanings, use `-f traits`. The trait name is lowercase with spaces, e.g. `deadly`, `free hand`.
5. Only remastered content exists for most core material. If a legacy name misses (e.g. Magic Missile, flat-footed, Power Attack), look up the new name with `pf.py -s 'Old Name' -f rules`. The `Remaster Changes > *` pages hold the rename tables.
6. Cite the record's source code and look up unfamiliar codes in `data/sources.txt` (`CODE|Title`). If PF2e and SF2e both have a record, say which game you're quoting.

## Files per game
`spells feats actions conditions traits(pf2e only; shared) equipment class-features classes ancestries ancestry-features heritages backgrounds deities effects creatures creature-lore creature-abilities hazards vehicles rules tables(pf2e) critical-deck(pf2e) boons-and-curses(pf2e) society-boons campaign(pf2e kingmaker) familiar-abilities(pf2e) pregens index`

`index.txt` is `Name|kind level|file`.

## Record format
`Name|kind level|SRC [R]|label:value|...|description`

- `R` means remaster content.
- Empty fields are omitted.
- In descriptions, ` / ` separates paragraphs, `/[Heading]/` marks a heading, and table rows are `cell,cell; next row`.
- `¦` stands for a literal pipe.

Common labels:
- `tr` traits. The rarity comes first if it isn't common.
- `act` action cost: `1a 2a 3a` = actions, `r` = reaction, `f` = free.
- `cast` spell casting time.
- `trad` spell traditions.
- `rng` range, `area` area, `tgt` targets, `def` save or defense, `dur` duration.
- `prereq`, `req`, `trig`, `freq`.
- Items:
  - `price`, `bulk` (`L` = light, `-` = negligible), `usage`.
  - `cat` category and group.
  - `dmg` damage (`S/P/B` = slashing/piercing/bludgeoning).
  - `AC`, `dexcap`, `chk` check penalty, `spd` speed penalty, `str` Strength requirement.
  - `hard` hardness, `HP`.
- Kinds for feats: `class feat N`, `general feat N`, `skill feat N`, `ancestry feat N`, `archetype feat N`, `classfeature N`, and so on.
- Classes: proficiency ranks are `U/T/E/M/L`. `features` lists `level Name`.

Creatures (`creature N`) and hazards:
- `pack` is the source bestiary.
- `tr` holds size first: `tiny sm med lg huge garg`.
- `perc` perception plus senses, `lang` languages, `skills`, and attribute modifiers.
- Defenses: `AC F R W`, `HP`, then `imm/weak/res`, then `spd` speeds.
- Strikes: `melee|ranged [act] Name +atk rngX (traits) damage`.
- `spells:Entry DCx atk+y: rank spells; C cantrips`.
- `ab:` abilities, formatted as `Name [act] (traits) text`.
- `gear` equipment.
- Hazards add `stealth`, `disable`, `routine` and `reset`.

## Rebuilding
The data is generated by `extract.py` in the ork-pf2e-tools repo from the foundryvtt/pf2e release `json-assets.zip` files. The release tags it was built from are in `data/VERSION`. To rebuild, run `./install.sh [--pf2e TAG] [--sf2e TAG]` from that repo. It defaults to the latest releases.
